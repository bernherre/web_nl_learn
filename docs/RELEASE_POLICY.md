# Release Policy

## Baseline

V18.18 is the preserved baseline for the 19.x line.

## Evolution rule

`new release = previous release + validated improvements`

Validated content, the verb atlas, exercises, images, the knowledge graph, navigation and accessibility features are not removed for convenience.

## Version objectives

- **19.1:** foundation and stability.
- **19.2:** learning experience, natural responses, real-life practice and validated visual exercises.
- **19.3:** product refinement and production candidate.
