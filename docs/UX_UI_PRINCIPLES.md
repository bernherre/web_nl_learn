# UX/UI Principles

## Product promise

Learning Dutch is already demanding. The interface must reduce effort, not add it.

## Principles

- **One primary task per screen.** The learner should immediately understand what to do next.
- **Progressive disclosure.** Advanced detail stays available without overwhelming beginners.
- **Consistency.** Navigation, spacing, typography, controls and feedback behave predictably.
- **Low cognitive load.** Use concise text, clear grouping, sufficient whitespace and restrained motion.
- **Immediate meaningful feedback.** Explain why an answer works and how Dutch speakers normally express it.
- **Mobile first and responsive.** All core functions remain usable on phone, tablet and desktop.
- **Accessible by default.** Keyboard support, visible focus, contrast, scalable text, transcripts and touch-friendly controls are mandatory.
- **Fast and calm.** The interface should feel responsive and visually quiet.
- **Preserve the existing essence.** Improvements refine the trusted navigation and visual identity instead of replacing them.

## Decision filter

A feature enters the product only when it improves learning, reduces user effort or increases consistency without creating avoidable complexity.
