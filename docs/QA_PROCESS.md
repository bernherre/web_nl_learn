# Quality Assurance Process

A release is accepted only after four forms of QA.

## Technical QA

- clean build;
- JavaScript syntax checks;
- automated tests;
- unique exercise and content identifiers;
- valid internal routes and local assets;
- offline cache version updated;
- no regression against the baseline counts.

## Linguistic QA

- official spelling and morphology;
- specific definitions;
- natural examples;
- correct fixed prepositions and collocations;
- synonyms validated by sense;
- register and regional variants explicitly marked.

## Pedagogical QA

- coherent CEFR progression;
- no hidden prerequisites;
- one unambiguous answer unless alternatives are explicitly supported;
- plausible distractors;
- explanations that teach the underlying pattern.

## UX QA

- primary action is clear;
- responsive layout;
- keyboard and focus behavior;
- readable typography and contrast;
- advanced detail does not obstruct the main task.
