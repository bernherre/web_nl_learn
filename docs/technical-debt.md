# Technische schuld V19.3 RC1

## Openstaand

- Woordgroepitems zonder afzonderlijk nagekeken lemma blijven eerlijk gemarkeerd als **controle nodig**; zij krijgen geen gegenereerde schijndefinitie.
- De klassieke bundle is bewust behouden voor eenvoudige statische hosting, maar blijft groot.
- Browser-spraaksynthese is afhankelijk van de lokaal beschikbare Nederlandse stemmen.
- Een volledige handmatige WCAG-audit met meerdere schermlezers blijft nodig voor de publieke V20-release.
