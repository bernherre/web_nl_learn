# Bijdragen

1. Werk in de bronbestanden, niet rechtstreeks in `js/app.js`.
2. Voeg inhoud toe met stabiele ids en Nederlandse definities.
3. Voer `npm run check` uit vóór elke commit.
4. Werk `CHANGELOG.md` bij voor zichtbare wijzigingen.
5. Verhoog versies alleen samen met interfaceversie en service-workercache.
